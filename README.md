# ToriMed Spa

Site for Tori Kruse (ToriMed Spa), a medical aesthetician inside The Beauty Collective, 191 Main Street, Fredericton, NB. Built to replace the Vagaro link in her Instagram bio. Live at https://torimed.ca (GitHub Pages, custom domain in `CNAME`, DNS at Namecheap).

A home page plus one page per service: Korean lash lift, lash lift and tint, brow lamination, Brazilian wax, waxing, facials, microchanneling, manicures and pedicures, and wedding and event makeup (`/makeup/`, an enquiry page with no price list).

## How to change it

Static HTML generated by a small Python script (standard library only).

    python3 src/build.py

- `src/content.py`: every service, price and appointment length, the home menu, and the copy for each service page. Change a price here and it updates everywhere.
- `src/templates/`: shared markup (header, footer, booking form, home page sections).
- `src/build.py`: turns the two above into `index.html`, one folder per service page and `sitemap.xml`.
- `assets/styles.css`, `assets/main.js`: styles, and the menu tabs, "your visit" picker and booking form. Form settings are in `SITE` at the top of `main.js`.
- `scripts/build_images.py`: cuts the photos from `_source/ig` (not in git) and writes `src/images.json`.

After changing CSS or JS, bump `asset_version` in `src/content.py` and rebuild so browsers fetch the new files. Never edit the generated HTML by hand.

The copy is written as Tori, in the first person. Brand colours are black and pink.
